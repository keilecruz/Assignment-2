# Assignment-2 

## Project Description
The website Birchmere University Campus Events is a website designed for students to discover and campus activties, events, and opportunities to get involved on campus. The website itself primarily has a working home page and a featured event page.

## Layout Decisions
When coming up with the design of the website itself I wanted it to be simple and easy to navigate, but also appealing to the eye to which I added in color for the links as well as for the background. For both the header and the footer of each of the pages it primarily stayed consistent to allow users to find the navigations link quicker and important information as well. The header mostly contianed the websites title, logo, tagline, and navigation links. Footer contained the contact information and the same navigation links from the header.

I primarily used a CSS Grid on the upcoming events section for the index page. The reason why this was mostly appropriate to use was because it would allow the event cards to be displayed in multiple columns and also have the cards be evenly spaced from one another instead of them being on top of each other.

I also did use a CSS Grid on the featured event to create the main content and sidebar layout. This primarily allowed the main event information and the additional event details to be displayed side by side instead of the information being placed in jsut one singular place which would overcrowd one another (also it doesn't look appealing). 

The flexbox was used for the navigation links in the header because flexbox makes it easier to arrange the links in a row, space between the links, and allow them to be wrapped. Not only that but the flexbox was also used in the footer and related events section in the featured event page to organize the content and make it evenly spaced out.

## Responsive Design 
I used two breakpoints for the website. I mostly tested the design out by resizing the browser window to see if the content stays readable and if the sections adjust correctly with a different browser size.

At 900px, the upcoming section events changes from three columns to two columns. Meanwhile for the event details page also changes from two columns to just one column.

At 600px, the upcoming events changes to one column. This is where the navigation also changes to a vertical layout to which the text and the spacing adjust to fit a more smaller screen.


## Semantic HTML
For this website I used several semantic elements.

<header> was primarily used on the top section of the website because this is where it contained the website title, logo, tagline, and navigations link.

<nav> was used as the navigation links to which allowed users to move between different pages and sections of the website.

<section> was used to organize different parts of the page such as the hero section, upcoming events, and related events.

<article> was used for every event card because of each card having it's own seperate content/information.
